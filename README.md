# Swing Girls & Boys

영화 <스윙걸즈>에서 출발한 인터랙티브 재즈 잼. 노트북 키보드·마우스·웹캠으로 처음 보는 사람도 재즈 밴드에 끼어 연주할 수 있게 만드는 것이 목표.

## 데모 실행 (`demo/`)

1. VS Code에서 `demo/index.html`을 Live Server로 열기 (또는 `npx live-server demo`)
2. 크롬에서 화면 클릭 또는 Enter → 막이 열리고 반주 시작
3. 인터넷 연결 필요 (p5.js, Tone.js, 피아노·드럼 샘플을 온라인에서 불러옴)

## 연주 방법 (두벌식 자판 기준)

- **자음 = 지금 코드** — 코드 진행(Dm7 → G7 → Cmaj7 → Am7)은 반주가 자동으로 넘김. 아랫줄 낮게 · 가운뎃줄 중간 · 윗줄 높게
- **모음 = 멜로디** — C 펜타토닉(도 레 미 솔 라), 아랫줄 → 윗줄로 갈수록 높은 음
- **Shift** = 더 세게
- 한글 이름을 타이핑하면 코드와 멜로디가 번갈아 나옴

## 잼 장치

- **박자 보정**: 친 음을 가장 가까운 스윙 박자에 맞춰 냄 (버튼으로 끄고 켤 수 있음)
- **받쳐주기**: 많이 칠수록 드럼·베이스 볼륨이 줄어듦
- **대답하기**: 한 소절 치고 멈추면 드럼이 필인으로 받아침

## 파일

| 파일 | 내용 |
|---|---|
| `demo/sketch.js` | p5.js 스케치 — 화면(막, 파형, 키보드), 입력 |
| `demo/piano.js` | 키 배치, 코드 진행과 보이싱, 피아노 소리 |
| `demo/audio.js` | 스윙 드럼, 워킹 베이스, 박자 보정, 밴드 반응 |
